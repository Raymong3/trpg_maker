# 🌈 무지개 열쇠 모험단 (Rainbow Key Adventures) TRPG

5세 아이와 부모님이 함께 즐길 수 있도록 간소화되고 이야기 중심적인 TRPG(테이블탑 롤플레잉 게임) 도구 세트입니다. 아빠가 게임 진행자(GM)가 되고, 엄마와 딸아이가 모험가(플레이어)가 되어 함께 흥미진진한 이야기를 만들어 보세요!

---

## 📂 파일 구조 및 소개

이 폴더(`trpg_maker`)에는 게임 플레이를 돕기 위한 다음 자료들이 들어있습니다:

1.  **`index.html` (웹 애플리케이션)**
    *   **룰북**: 게임 방법과 GM을 위한 팁을 쉽게 읽을 수 있습니다.
    *   **모험가 카드 (캐릭터 시트)**: 2명의 모험가 카드를 독립적으로 편집하고 동시에 관리할 수 있습니다. 종이로 인쇄하여 색칠 놀이처럼 쓸 수 있는 **프린트 전용 레이아웃**도 지원합니다.
    *   **주사위 광장**: 실제 주사위가 없을 때 화면을 터치해 굴릴 수 있는 가상 주사위 도구입니다. 2명 중 굴릴 캐릭터를 선택하면 해당 캐릭터의 능력치가 주사위 개수에 자동으로 반영되며, 판정 결과를 알기 쉽게 표시해 줍니다.
    *   **시나리오 북**: 아빠 GM이 게임을 수월하게 진행할 수 있도록 안내해 주는 모바일/태블릿용 시나리오 가이드입니다.
2.  **`rules.md` (오프라인 룰북)**
    *   게임 규칙과 아이와 놀아줄 때 유용한 '아빠 GM 3대 규칙'이 한글 마크다운으로 정리되어 있습니다.
3.  **`adventures.md` (시나리오 마크다운)**
    *   두 가지 귀여운 동화풍의 모험 이야기 시나리오입니다:
        *   *제1화: 잃어버린 아기 곰의 딸기 케이크*
        *   *제2화: 반짝반짝 별나라 요정의 눈물*

---

## 🚀 실행 방법

### 1. 웹 브라우저에서 바로 열기
*   `trpg_maker` 폴더 안에 있는 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등 평소 사용하는 웹 브라우저에서 엽니다.
*   **태블릿이나 모바일 폰**에 파일을 넣어서 열거나, 컴퓨터 화면을 띄워놓고 보시며 플레이하기 좋습니다.

### 2. 캐릭터 시트 인쇄하기
*   `index.html`에서 **[모험가 카드]** 탭으로 들어간 후, 인쇄하고 싶은 캐릭터 아래의 **[모험가 X 카드 인쇄]** 버튼을 누릅니다.
*   프린터로 인쇄하면 아이가 직접 이름을 쓰고, 캐릭터 그림을 그리고 색칠할 수 있는 귀여운 종이 시트가 출력됩니다!

## 🎲 5세 아이와 함께할 때의 꿀팁

*   **실제 과자나 초콜릿 사용하기**: 게임 캐릭터의 하트(체력)가 깎였다가 회복될 때, 실제로 젤리나 캔디를 입에 쏙 넣어 주면 아이가 훨씬 더 몰입하고 좋아합니다!
*   **아이의 엉뚱함 환영하기**: 아이의 상상력이 규칙이나 물리 법칙에 맞지 않더라도 "그래, 그리고..."(Yes, and...) 기법을 사용해 다 받아주며 이야기를 더 신나게 굴려 주세요.
*   **무서움 없애기**: 몬스터가 등장해서 무서워하면 즉시 "그런데 이 괴물은 사실 재채기 대장이라 무지개 거품을 내뿜어!" 하고 코믹하게 바꾸어 주세요.
